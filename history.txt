0.1.3

- First implementation of project creation using the "new" command; it now generates the basic files for a new project.

- Improvements to the "new" command: it not only generates the basic files (which were empty in the previous step), but also organizes them into folders for better project readability and injects basic templates if needed.

0.1.25

- Corrections to the "new" command: it now asks for confirmation if you want to continue if the project already exists. This was already implemented, but the dialog text has been simplified.

0.1.2

- Implementation of the getPath function to obtain the path from where the awtly.py script is executed; checks will be made to test that it works on Linux.
- The getPath function works perfectly on Windows, but on Linux the script started producing errors; you have to define 'Final' for constants using 'from typing import Final'.
- Partial implementation of the "new" command; it can now create a folder for the project, but it has only been tested locally. It hasn't yet been tested with absolute paths to see if it works. If the folder already exists, Awtly will ask if you want to delete it and create it again, overwriting the contents of the previous folder in the process. If you choose "No," the folder will remain, and the core files will be overwritten.

0.1.1

- Minor fixes: The "Help" command (help, /?, and -h) has been implemented displaying general help on the commands supported by Awtly.
- The -v command has been implemented to display the current Awtly version.
- Awtly now checks if basic commands are incomplete and suggests using the "Help" command to ensure the user types the commands correctly.

0.1.0

- The Awtly project begins, it aims to create a programming language that is easy to learn and implement, but that transpiles to PHP with the ability to create advanced projects with little effort.
- First implementation in Python, it already detects the basic commands to run the transpiler (new, delete, and build), although for now they do nothing.
- The first message translator was created to display notices in the operating system's language.
